# G2NRaiGuide

База знаний для ИИ, который разрабатывает модификации Gothic. Рецепты, примеры кода и результаты проверок из разных проектов помогают решать новые задачи на ZenGin и Union.

Дайте ИИ ссылку на этот репозиторий, ссылку на проект, если он уже есть, и задачу. Попросите начать с [AGENTS.md](AGENTS.md).

> Прочитай `AGENTS.md` в `G2NRaiGuide` и разделы, относящиеся к задаче. Используй подходящие примеры для моей версии игры. Сделай окно торговли для NPC с выбором товара мышью.

Первые рецепты собраны на примере Odyssee Quest Inspector для Gothic II «Ночь Ворона». У каждого рецепта есть версия, исходники и результат проверки. [Исходный проект](https://github.com/piratvasyamorexod-alt/OdysseeQuestInspector/tree/180e38e05d50d66dcf1ba702e3c10e4dd01b9fab)
