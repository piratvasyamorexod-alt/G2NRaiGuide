# G2NRaiGuide

База знаний для ИИ, который разрабатывает модификации Gothic. Рецепты, примеры кода и результаты проверок из разных проектов помогают решать новые задачи на ZenGin и Union.

Дайте ИИ ссылку на этот репозиторий, ссылку на проект, если он уже есть, и задачу. Попросите начать с [AGENTS.md](AGENTS.md).

> Прочитай `AGENTS.md` в `G2NRaiGuide` и разделы, относящиеся к задаче. Используй подходящие примеры для моей версии игры. Сделай окно торговли для NPC с выбором товара мышью.

Первые рецепты собраны на примере Odyssee Quest Inspector для Gothic II «Ночь Ворона». У каждого рецепта есть версия, исходники и результат проверки. Раздел о мыши описывает управление, подтвержденное в пользовательской сборке «Одиссеи», и показывает, как диагностировать события, координаты и рывки курсора. [Мышь на паузе](docs/union/mouse-input.md) · [Исходники 1.0.7](https://github.com/piratvasyamorexod-alt/OdysseeQuestInspector/tree/c6cacbd167837afe84364069ecc25a29e97bca81)

В разделе об инвентаре собраны решения из G2NRinventory. Они охватывают перетаскивание без случайного применения, хранение хотбара и отметок книг, торговлю и завершение работы игры. [Инвентарь, торговля и хотбар](docs/union/inventory.md)
