# Анимации персонажей

Раздел открыт для первого воспроизводимого примера. Полный маршрут от Blender до воспроизведения в игре здесь еще предстоит проверить.

Для первой записи подойдет короткий оригинальный жест NPC. Укажи версию Gothic, модель и скелет, версию Blender и инструмента импорта и экспорта. Сохрани рабочие параметры масштаба, осей и кадров, небольшой исходный файл и настройки экспорта. Добавь точные имена файлов, пример регистрации анимации у целевой модели и способ запустить ее в игре.

При проверке запиши, проигрался ли жест целиком, сохранились ли положение и ориентация персонажа и вернулся ли NPC в обычное состояние после завершения. Этого примера должно хватить, чтобы следующий ИИ мог подготовить другое движение для той же связки инструментов.
