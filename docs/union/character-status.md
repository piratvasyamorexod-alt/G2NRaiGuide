# Окно характеристик активного мода

Рецепт для Gothic II «Ночь Ворона» 2.6 fix (G2A), Windows x86 и Union. Проверенная ревизия примера — G2NRcharstats 0.1.1. [Исходники](https://github.com/piratvasyamorexod-alt/G2NRcharstats/tree/059fe19279dbde91931c95abc672aee8ef06279e) · [Оформление игровых окон](modal-ui.md#единый-стиль-игровых-окон)

## Перехват штатного окна

1. Оберни `oCStatusScreen::Show()` (G2A 2.6 fix, `0x0047ED60`) короткой сессией, привязанной к `m_pStatusMenu`. Вызови оригинал. Он вызывает `oCMenu_Status::InitForDisplay()` (`0x0047DDC0`), затем запускает меню. В «Одиссее» скриптовый хук в конце `InitForDisplay()` записывает дополнительные значения через `zCMenuItem::SetText()`.
2. При первой отрисовке активного меню, когда `m_screenInitDone` выставлен, обойди `m_listItems`. Возьми ID, координаты и `GetText(0)` у каждой подходящей строки. Храни копии текста для отрисовки. У обычных элементов проверь `owner`, `GetIsVisible()` и `m_bDontRender`. Группируй строки по позиции с допуском на небольшие смещения столбцов. Так сохраняются подписи, язык, навыки и формат значений текущих скриптов, включая пары вроде `46%/31%`.
3. В хуке `zCView::DrawItems()` (`0x007A6750`) подмени отрисовку самого `m_pWindow` этой сессии. Другие поверхности передавай оригиналу. Если список пуст или содержит неизвестный вид виджетов, оставь штатное окно. Управление паузой и основной жизненный цикл остаются у движка. [Открытие и хуки](https://github.com/piratvasyamorexod-alt/G2NRcharstats/blob/059fe19279dbde91931c95abc672aee8ef06279e/src/Plugin.ipp#L464-L529) · [Чтение элементов и группировка](https://github.com/piratvasyamorexod-alt/G2NRcharstats/blob/059fe19279dbde91931c95abc672aee8ef06279e/src/Plugin.ipp#L34-L75) · [Группировка по строкам](https://github.com/piratvasyamorexod-alt/G2NRcharstats/blob/059fe19279dbde91931c95abc672aee8ef06279e/src/status_layout.hpp#L42-L84)

## Страницы «Одиссеи» 2.7.5.2

В `MENU_STATUS` пункт `MENU_ITEM_SWITCH_HANDICRAFT_CHOICE` выбирает значение `MOD_ODYSSEE/showMoreInfo`. У строк обеих страниц то же имя настройки в полях `m_parHideIfOptionSectionSet` и `m_parHideIfOptionSet`. Значение `m_parHideOnValue` указывает страницу, на которой строку следует скрыть. Механизм выбора меняет настройку, а видимость пересчитывается при подготовке штатного меню. Старый путь с отправкой `KEY_RIGHT` и `KEY_RETURN` из клика приводил к устаревшему списку и мерцанию при закрытии. `Enter` запускает `MENU_STATUS` повторно через `SEL_ACTION_STARTMENU`.

Сними два снимка строк за одно открытие. Применяй условие страницы только к элементам, чья настройка совпадает с распознанным переключателем. Такие элементы могут лежать в `m_listItems` с заполненным текстом, даже когда их нет среди видимых дочерних элементов. Для остальных строк используй их штатную видимость. Рецепт предполагает, что мод уже заполнил тексты обеих страниц. Это проверяется в скрипте обновления меню конкретной версии мода.

```cpp
// page is 0 or 1. Use -1 when the row has no matching page setting.
bool VisibleOnPage(bool nativeVisible, int hideOnPage, int page) {
    return hideOnPage == 0 || hideOnPage == 1 ? page != hideOnPage : nativeVisible;
}
```

Клик по вкладке и стрелки меняют индекс снимка внутри окна. Обработчик перехватывает `Enter` для этого переключателя. При `Esc` прекращай брать ввод для вкладок и подавляй остаточные кадры штатной панели до выхода из `Show()`. Сохраняй это условие и после того, как движок уже сменил активное меню. Мышь освобождается при выходе из сессии или потере фокуса.
